# AI Data Analysis Agent

An AI-powered data analysis application that helps users analyze datasets, identify data quality issues, explore patterns, and generate meaningful insights.

## 🚀 Live Demo

[Click here to use the AI Data Analysis Agent](https://ai-data-analysis-agent-3nnukwxfk6snwr4fr3wygh.streamlit.app/)

## 📌 Project Overview

The AI Data Analysis Agent is designed to simplify the data analysis process. Users can upload datasets and explore their data through automated analysis and visualizations.

## ✨ Features

- Upload CSV and Excel datasets
- Preview uploaded data
- Identify missing values
- Detect duplicate records
- Explore dataset columns and data types
- Generate statistical summaries
- Visualize data through charts
- Discover patterns and insights

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Data Visualization Libraries
- AI Integration

## 🎯 Project Objective

To make data analysis easier, faster, and more accessible through automation and AI assistance.
